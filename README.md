# Misa Amane Birthday Website 🎀

A mobile-friendly, single-page birthday surprise. It includes a teacher's birthday letter, interactive cake, countdown, hidden message, fireworks, and an original synthesized birthday melody.

## Publish it with GitHub Pages (free)

1. Sign in to [GitHub](https://github.com/).
2. Select **New repository**. Name it `misa-birthday`.
3. Set the repository to **Public**, then create it.
4. Choose **Add file → Upload files** and upload `index.html` from this folder. You may also upload this README.
5. Commit the upload.
6. Open **Settings → Pages** in the repository.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Choose branch **main** and folder **/(root)**, then press **Save**.
9. Wait a minute or two. GitHub will show the published URL in the Pages section. It will look like `https://YOUR-USERNAME.github.io/misa-birthday/`.
10. Open that URL on your phone to test it, then share it with Misa.

## Customize

Open `index.html` in any text editor. Search for `Misa Amane`, the birthday date, or the letter text to edit them. The countdown is set to 25 November 2026. The site uses no external libraries or image assets.

## Notes

- The music starts only after the visitor taps the play button, because browsers block autoplay.
- The countdown uses the visitor's device local time.
- GitHub Pages is public: anyone with the link can view the page. Avoid adding private student information or photos without permission.
